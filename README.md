# Mahmoud Youssef — Backend Software Engineer Portfolio

Personal portfolio website showcasing backend engineering projects, technical focus, and professional background as a Backend Software Engineer specializing in Java and Spring Boot.

## Highlights

- **Dark Minimal Design:** Monochrome aesthetic, high performance, fully responsive layout.
- **9 Featured Projects:** Production-oriented backend systems — distributed URL shortener, multi-tenant e-commerce, realtime messaging, delivery platform, donation matching, graduation project, scheduler, reservations, and traffic-rules API.
- **Technical Focus:** Backend engineering, data & distributed state, security & reliability, cloud & infrastructure.
- **Interactive Widgets:** Floating GitHub stats modal, image lightbox, scrollspy navigation.
- **Typography:** Plus Jakarta Sans & Space Mono.

## Tech Used

- **Frontend & Styling:** HTML5 + Tailwind CSS (CDN)
- **Interactivity:** Alpine.js + vanilla JavaScript
- **Icons:** RemixIcon + Devicons + Simple Icons

## Run Locally

Any static server works:

```bash
git clone https://github.com/MahmoudYoussef-web/portfolio-.git
cd portfolio-
python -m http.server 8000
# open http://localhost:8000
```
